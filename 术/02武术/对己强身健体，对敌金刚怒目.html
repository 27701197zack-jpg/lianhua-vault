武术 — 对己强身健体，对敌金刚怒目

「吾宗以禅入武，以武悟道。平日修身养性，战时一击必杀。」 —— 少林武谚

「未学艺，先学礼；未习武，先习德。」 —— 武术格言

一、武术总论

武术的定义

武术（古称「武艺」「技击」「国术」「功夫」）是中国传统的格斗、健身、修身、悟道体系，以踢、打、摔、拿、跌、击、刺等技法为核心，融合儒释道三家思想，讲究「内练一口气，外练筋骨皮」。

武术的本质：

  • 对外：克敌制胜的格斗术
  • 对内：强身健体的导引术
  • 对上：悟道修行的法门（以武入道）

核心地位：

  • 五学中「术」的重要组成部分
  • 与导引、气功、中医密切相关
  • 《纪效新书》《手臂录》《太极拳谱》《易筋经》是经典

历史演变：

  • 先秦：角力、手搏、剑道
  • 汉代：武术与舞蹈结合（百戏）
  • 唐代：武举制度，武术系统化
  • 宋代：民间武术兴盛，出现门派
  • 明代：戚继光《纪效新书》系统总结军旅武术
  • 清代：内家拳兴起（太极、形意、八卦），门派林立
  • 民国：称「国术」，中央国术馆成立
  • 当代：竞技武术、健身武术、传统武术并存

三、少林派详解

少林寺与武术

传说：

  • 达摩面壁：传说达摩在少林寺面壁九年，创立「易筋经」「洗髓经」，为少林武术之源
  • 历史考证：少林武术实际形成于隋末唐初，与达摩关系不大

历史：

  • 隋末：少林寺僧助唐王李世民，获赐田产，武功始盛
  • 明代：少林武术大成，出现「少林棍僧」抗倭
  • 清代：禁武，少林武术转入民间
  • 民国：少林武术复兴，出现众多分支

四、武当派详解

武当山与武术

传说：

  • 张三丰（元明之际）在武当山修道，观蛇鹤相斗，悟出太极拳
  • 历史考证：太极拳实际形成于明末清初，与张三丰关系有待考证

武当武术特点：

  • 以柔克刚：不硬碰硬，借力打力
  • 以静制动：先让后打，后发先至
  • 以意领气：意念引导内气运行
  • 以气运身：内气催动外形
  • 圆活连贯：动作圆活，连绵不断

太极拳经典原文

王宗岳《太极拳论》：

太极者，无极而生，动静之机，阴阳之母也。动之则分，静之则合。无过不及，随曲就伸。人刚我柔谓之走，我顺人背谓之粘。动急则急应，动缓则缓随。虽变化万端，而理唯一贯。

由着熟而渐悟懂劲，由懂劲而阶及神明。然非用力之久，不能豁然贯通焉。

2. 形意拳

创始人：李洛能（清代），传自山西姬际可 核心思想：「象形取意」—— 模仿动物姿态，取其精神

五行拳

拳法五行脏腑特点手法步法
劈拳金肺如斧劈，自上而下掌劈直线
崩拳木肝如箭射，直进直出拳冲直线
钻拳水肾如泉水，上钻拳钻直线
炮拳火心如炮发， explosive拳翻直线
横拳土脾如横梁，横挡拳横直线

五行相生：劈（金）→ 钻（水）→ 崩（木）→ 炮（火）→ 横（土）→ 劈（金） 五行相克：劈（金）克崩（木）；崩（木）克横（土）；横（土）克钻（水）；钻（水）克炮（火）；炮（火）克劈（金）

九、武术与修行（以武入道）

武术修炼层次

层次武术境界修行对应特征
第一层：练形学招式、练套路炼精身体强健、招式熟练
第二层：练气练呼吸、发劲炼精化气内气充盈、劲力整实
第三层：练意以意领气、用意不用力炼气化神意到气到、劲随意发
第四层：练神感而遂通、不假思索炼神还虚神明之境、本能反应
第五层：合道无招无式、人拳合一炼虚合道以无法为有法、大道至简

以武入道的路径

路径方法目的
** martial arts → 导引 → 内丹**从外家入手，转内家，再入内丹身体 → 气 → 神
** martial arts → 静坐 → 悟道**练拳后静坐，体悟动静之机动中静 → 静中动
** martial arts → 禅 → 悟道**如少林禅武合一武即禅、禅即武
** martial arts → 太极 → 道家**太极拳本身就是道家修炼拳即道、道即拳

武术中的道家修炼要素

武术要素道家修炼说明
站桩筑基无极桩 = 入静；混元桩 = 聚气
慢练文火温养慢中炼气
呼吸调息腹式呼吸 = 胎息入门
意念凝神意守丹田 = 凝神入气穴
松静虚静松到虚、静到无 = 入定
发力采药发劲时气聚丹田 = 产药
收势封固收式时气归丹田 = 结丹

十四、经典原文摘录

王宗岳《太极拳论》

太极者，无极而生，动静之机，阴阳之母也。动之则分，静之则合。无过不及，随曲就伸。人刚我柔谓之走，我顺人背谓之粘。动急则急应，动缓则缓随。虽变化万端，而理唯一贯。

由着熟而渐悟懂劲，由懂劲而阶及神明。然非用力之久，不能豁然贯通焉。

虚领顶劲，气沉丹田。不偏不倚，忽隐忽现。左重则左虚，右重则右杳。仰之则弥高，俯之则弥深，进之则愈长，退之则愈促。

戚继光《纪效新书·拳经捷要篇》

拳法之要，在于快、硬、力、活。快者，速也；硬者，坚也；力者，劲也；活者，变也。四者兼备，方能制敌。

学拳要身法活便，手法便利，脚法轻固，进退得宜。腿可飞腾，而其所谓飞腾者，乃腾身飞起，脚踢敌人之头面、咽喉、心胸、胁肋、腰胯、膝胫也。

少林武谚

练武不练功，到老一场空。 练功不练腰，终究艺不高。 内练一口气，外练筋骨皮。 手是两扇门，全靠腿打人。 一寸长一寸强，一寸短一寸险。 拳不离手，曲不离口。 一日练一日功，一日不练十日空。 冬练三九，夏练三伏。

形意拳谱

鸡腿、龙身、熊膀、虎抱头。 起如钢锉，落如钩竿。 不钻不翻，一寸为先。 脚踏中门夺地位，就是神仙也难防。
