骨相 — 骨有九种，人有九贵

「骨相之法，先察头骨之形，次审周身之骨。骨为髓之府，髓为骨之充，骨相定一生之格局。」 —— 骨相概要

「骨为体之干，相为骨之表。观其骨，知其命；观其相，知其运。骨相合一，方得全功。」

一、骨相总论

骨相的定义

骨相术是通过观察人的头骨形状、骨骼粗细、骨节大小、骨架结构、骨骼质地，来推断其先天禀赋、性格气质、命运格局、寿夭福禄的术数。

核心原理：「骨为髓之府，髓为精之华」—— 骨骼是人体的「框架」，决定了人的基本格局。骨相是「内相」，面相是「外相」；骨相决定先天，面相反映后天。

与中医的关系：中医认为「肾主骨，生髓，通于脑」，骨骼的强弱直接反映先天肾气的盛衰。

经典著作：

  • 《月波洞中记》 —— 唐代，骨相专书
  • 《玉管照神局》 —— 唐代，含骨相专章
  • 《麻衣神相·骨相篇》 —— 宋代
  • 《柳庄相法·骨相篇》 —— 明代
  • 《神相全编·骨相篇》 —— 明代

二、头部骨相

九贵骨详解

传统相学认为头部有九块最重要的「贵骨」，这九骨决定了一个人的先天格局：

1. 天庭骨

项目内容
位置额头正中，发际至眉心
理想形态高阔、丰隆、平满、如覆肝
主事少年运（15-30岁）、智慧、祖荫、官禄
吉相天庭饱满如满月，聪明早发，祖荫深厚
凶相天庭低窄、凹陷、有疤痣，少年运差
摸骨法以掌心贴额，感觉骨骼是否高阔丰满

2. 枕骨

项目内容
位置后脑正中，风府穴上方
理想形态强实、突出、如连山、如覆杯
主事晚年运（50岁后）、根基、定力、寿元
吉相枕骨高凸，晚年安康，寿元绵长
凶相枕骨低平、凹陷，晚年孤独，根基浅薄
摸骨法以手指按压后脑，感觉骨骼是否强实
特殊连山枕（枕骨高凸如连山）：大贵，掌权

3. 顶骨

项目内容
位置头顶正中，百会穴处
理想形态平正、圆隆、如天穹
主事一生格局、天命、总体运势
吉相顶骨平正圆隆，天命不凡，格局宏大
凶相顶骨尖凸、偏斜、凹陷，格局有限
摸骨法以掌心覆顶，感觉是否平正圆隆
特殊顶骨尖凸（反骨）：天才或叛逆，极端

4. 佐串骨（鬓骨/辅角骨）

项目内容
位置头顶两侧，太阳穴上方，鬓角内侧
理想形态角起、棱明、如角插入发际
主事权力、开创、威严、社会地位
吉相佐串骨角起棱明，有权有势，威震四方
凶相佐串骨低平、凹陷，无权无势
摸骨法以双手按太阳穴上方，感觉是否有角棱
特殊此骨高耸者，多为领导、将军、企业家

5. 太阳骨

项目内容
位置太阳穴，眉尾至发际之间
理想形态直线隆起、如天柱
主事贵显、成功、事业高峰
吉相太阳骨隆起如柱，事业有成，贵显
凶相太阳骨凹陷，事业平平
摸骨法以手指按太阳穴，感觉是否隆起

6. 眉骨（棱骨）

项目内容
位置眉棱上方，眼眶上缘
理想形态棱而不露、微凸、有肉包
主事果断、魄力、意志力
吉相眉骨微凸有肉，果断有魄力，刚正
凶相眉骨过露（棱骨突兀），性格暴躁，刑克；眉骨过低，懦弱无主见
摸骨法以手指按眉棱，感觉骨骼是否适度凸起

7. 鼻骨（山根骨/年寿骨）

项目内容
位置鼻梁正中，从山根至鼻尖
理想形态挺直、丰隆、有梁
主事财运、自我、中年事业
吉相鼻骨挺直丰隆，财运亨通，自信
凶相鼻骨塌陷、歪斜，财运差，自卑
摸骨法以手指从山根摸至鼻尖，感觉是否挺直
特殊鼻骨贯顶（鼻高至额）：大贵

8. 颧骨（权骨）

项目内容
位置面颊上方，眼眶外下方
理想形态丰隆、有势、圆起、插入鬓角
主事权力、领导力、社会能力、掌控力
吉相颧骨丰隆有势，有权有领导才能
凶相颧骨低平，无权；颧骨过高过尖（颧骨横张），克夫克妻，刑克
摸骨法以手指按面颊上方，感觉是否丰隆
特殊颧骨插天仓（颧骨入鬓）：大贵，掌权

9. 颏骨（地阁骨/下巴骨）

项目内容
位置下巴正中，承浆至地阁
理想形态方圆、厚重、朝拱、如双足并立
主事晚年、子女、意志、田产
吉相地阁方圆厚重，晚年安康，子女贤孝
凶相地阁尖削、后缩，晚年孤独，子女缘薄
摸骨法以手指托下巴，感觉是否方圆厚重
特殊地阁朝拱（下巴前突）：晚年掌权

六、骨相与面相的关系

骨相为内，面相为外

骨相面相综合判断层次
骨好 + 相好内外皆美大富大贵，一生平顺上上等
骨好 + 相差内佳外劣先天好，后天不修；或大器晚成中上等
骨差 + 相好内劣外佳先天不足，后天努力；或虚有其表中下等
骨差 + 相差内外皆劣需大努力，或命运多舛下下等

骨相为「先天」，面相为「后天」:

  • 骨相难以改变（除非重大事故或整容手术）
  • 面相可随心态、修养改变（表情习惯改变肌肉形态）
  • 骨相决定「上限」，面相决定「当下」
  • 骨相好而相差：年轻时辛苦，中年后发力（大器晚成）
  • 骨相差而相好：年轻时有成，中年后走下坡（先成后败）

九、骨相与健康

中医视角

中医认为「肾主骨，生髓，通于脑」：

  • 骨骼强健 → 肾气充足 → 精力充沛、智力好、寿命长
  • 骨骼软弱 → 肾气不足 → 精力差、易疲劳、发育迟缓
  • 骨骼疼痛 → 肾气问题或外邪侵袭 → 需调理
  • 骨质疏松 → 肾精亏虚 → 补骨脂、杜仲、续断

十、骨相实例分析

案例一：大器晚成

骨相：

  • 枕骨强实、顶骨圆隆（先天格局大）
  • 天庭骨低窄（少年运差）
  • 颧骨丰隆（有权力欲）
  • 鼻骨中年才挺直

面相：

  • 早年面相差：额头窄、眼无神、气色暗
  • 中年后面相变好：印堂渐开、眼神有光、气色明润

分析：

  • 骨相好 → 先天格局大
  • 少年面相差 → 早年不得志
  • 中年后面相变好 → 后天努力改变运势
  • 结论：大器晚成，中年后发达

案例二：先成后败

骨相：

  • 天庭饱满（少年运好）
  • 枕骨凹陷（晚年根基差）
  • 地阁尖削（晚年差）

面相：

  • 早年面相好：天庭饱满、眼神明亮
  • 中年后面相变差：眼神变浊、气色变暗、法令纹深陷

分析：

  • 骨相上下停反差大 → 先好后差
  • 早年面相好 → 少年得志
  • 中年后面相变差 → 后天不修（可能骄傲、纵欲、懒惰）
  • 结论：先成后败，需修心保晚节

骨为体之干，肉为骨之衣。骨坚者寿，骨弱者夭。骨露者贫，骨藏者富。

十三、现代视角

颅相学批判

颅相学（Phrenology）：19世纪初由德国医生弗朗茨·约瑟夫·加尔（Franz Joseph Gall）创立，认为头骨形状反映大脑发育，从而反映性格和智力。

方面颅相学科学评价
头骨形状反映大脑发育部分正确
大脑区域不同区域负责不同功能部分正确（功能分区）
头骨凸起反映大脑该区域发达错误（头骨形状与脑功能无关）
性格推断通过摸头骨推断性格伪科学
历史影响19世纪流行已被科学证伪

结论：颅相学已被证伪，但现代神经科学证实大脑确实有功能分区（如布洛卡区、韦尼克区等），只是与头骨形状无关。

骨密度与命运

现代医学发现：

  • 骨密度高 → 激素水平正常 → 精力充沛 → 行为积极 → 「运势好」
  • 骨密度低 → 激素失衡 → 精力差 → 行为消极 → 「运势差」
  • 这提供了一个生理学解释：骨相可能间接反映激素水平，从而影响行为和结果

骨相的理性看待

角度评价
遗传学骨骼形状与遗传有关，但不直接决定命运
发育学胎儿期和儿童期营养影响骨骼发育
行为学骨骼影响体型，体型影响自我认知和他人印象
社会学身高、骨架大的人在某些社会中获得更多机会
统计学某些骨相特征可能与某些性格特征有弱相关

十五、特殊骨相

反骨

位置：后脑勺枕骨突出如反弓 历史名人：魏延（传说）、朱元璋 含义：

  • 叛逆、不安分、不甘人下
  • 英雄造时势
  • 极端性格：大成功或大失败
  • loyalty 问题（容易背叛或被背叛）

伏羲骨（日角月角骨）

位置：额角两侧，日角在左，月角在右 含义：

  • 日角骨：父缘、祖荫
  • 月角骨：母缘、福泽
  • 日角月角俱隆：父母双全，祖荫深厚
  • 日角月角凹陷：父母缘薄，白手起家
  • 日角月角有棱：大贵，公侯将相

龙角骨（辅角骨）

位置：眉尾上方，延伸至额角 含义：

  • 龙角骨起：大贵，非凡人
  • 龙角骨棱：有权威，能服众
  • 龙角骨平：平常人

巨鳌骨（耳后骨）

位置：耳朵后方，枕骨两侧 含义：

  • 巨鳌骨起：耳后见骨，大寿
  • 巨鳌骨平：平常
  • 巨鳌骨陷：短寿

将军骨（颧骨上方）

位置：颧骨上方，眼眶外上缘 含义：

  • 将军骨起：武贵，将军之相
  • 将军骨平：文职
  • 将军骨陷：无权

驿马骨（颧骨下方）

位置：颧骨下方，面颊骨 含义：

  • 驿马骨起：奔波得财，异乡发达
  • 驿马骨平：安稳
  • 驿马骨陷：漂泊劳碌

内丹炼骨

道家内丹认为：

  • 炼精化气：气入骨 → 骨节作响（虎啸龙吟）

  • 炼神还虚：骨相自变 → 脱胎换骨

经典：「炼精化气，骨节如雷鸣；炼气化神，头骨自鸣。」
