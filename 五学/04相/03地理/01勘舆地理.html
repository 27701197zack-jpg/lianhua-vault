勘舆地理 — 寻龙点穴的风水秘术

「气乘风则散，界水则止。古人聚之使不散，行之使有止，故谓之风水。」 —— 郭璞《葬书》

一、勘舆总论

勘舆（又称「风水」「青乌术」「青囊术」）是通过观察地形地貌、山川河流、方位朝向、气场流动，来选择住宅、墓地、城池的最佳位置，以达到趋吉避凶、福荫子孙目的的术数。

核心地位：

  • 五学中「相地」的核心方法
  • 与建筑学、环境学、生态学密切相关
  • 《葬书》《青囊经》《阳宅十书》是经典

二、风水的基本原理

1. 气的理论

郭璞《葬书》：

「葬者，乘生气也。夫阴阳之气，噫而为风，升而为云，降而为雨，行乎地中而为生气。」

气的运行规律：

  • 气乘风则散 → 需要藏风
  • 气界水则止 → 需要得水
  • **「风水」**之名即来源于此：藏风 + 得水

2. 阴阳与四象

理想的风水格局（「四象」）：

方位名称地形功能
后方（北）玄武高山/楼宇靠山、屏障、藏风
前方（南）朱雀开阔平地/水池明堂、视野、聚气
左方（东）青龙稍低的丘陵/建筑辅佐、护卫
右方（西）白虎稍低的丘陵/建筑辅佐、护卫

理想格局：背山面水，左辅右弼，藏风聚气。

3. 龙脉理论

龙脉：山脉的走势被视为「龙」的躯体，生气沿山脉流动。

龙脉部位地形功能
祖山山脉起源的最高峰龙之始祖
少祖山主山前的次高峰龙之父母
主山（玄武）穴后的靠山龙之躯干
护砂（青龙白虎）左右两侧的山丘龙之护卫
案山穴前较近的山丘龙之案几
朝山穴前较远的山峰龙之朝拜
水口水流出口处龙之门户

点穴：找到龙脉上生气最聚集的点（「穴」），用于建房或安葬。

四、阴宅风水（墓地风水）

1. 点穴原则

  • 寻龙：沿山脉走势找生气流动之脉
  • 察砂：观察左右护砂的形态
  • 观水：看水流的方向、形态（环抱为吉，反弓为凶）
  • 点穴：在龙脉生气最聚集处下葬
  • 立向：确定墓碑朝向

2. 水法

水形名称吉凶原因
环抱水玉带水吉气聚，有情
直去水割脚水凶气散，无情
反弓水反弓水凶气被带走
直冲水枪煞水凶气被冲散
汇聚水聚宝盆吉气聚，聚财

3. 阴宅与后人

传统认为：

  • 祖先葬在好风水处 → 后人得福荫
  • 祖先葬在坏风水处 → 后人受祸
  • 原理：「祖气感通」—— 祖先的骨骸与后人的血脉相连，气场共振

现代诠释：

  • 可能是心理暗示（祖坟好 → 后人有信心 → 更易成功）
  • 可能是环境因素（祖坟环境好 → 后人扫墓时心情好 → 家族凝聚力强）

六、现代视角

科学解释

风水原则科学解释
背山面水避风、采光、近水源
坐北朝南采光、避北风（中国北方）
明堂开阔视野好、通风好、心情好
避开路冲减少噪音、尘土、安全隐患
近水方便用水、调节温度、景观好
不近悬崖避免滑坡、落石

环境心理学

  • 自然景观 → 降低压力、提升幸福感
  • 视野开阔 → 心情开阔、创造力提升
  • 背有靠山 → 心理安全感
  • 左右有护 → 心理保护感

生态学

  • 风水林 → 保护水源、保持水土、提供生物栖息地
  • 风水池 → 调节小气候、防火、灌溉
  • 风水选址 → 常选择生态位最佳的位置（避风向阳、近水源、土壤肥沃）

十、峦头理气结合

峦头为体，理气为用

层面作用比喻
峦头确定大格局身体
理气确定方位时机衣服
两者结合最佳风水得体着装

峦头理气互参法

步骤：

  1. 先看峦头：龙脉、穴位、砂水大势
  2. 再测理气：罗盘定向，飞星排盘
  3. 综合判断：峦头吉+理气吉 = 大吉
  4. 择日动工：结合八字择吉日
情况峦头理气结果
A吉吉上上，速发
B吉凶中平，减分
C凶吉中平，可救
D凶凶大凶，避之
