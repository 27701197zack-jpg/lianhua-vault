外丹炼术 — 炉火与药石的古老智慧

「丹砂入火，化为水银；水银入火，复化为丹。」 ——《周易参同契》

一、源流与典籍原文

外丹源流

传说起源：

「外丹之术，传自黄帝。黄帝命容成子作火法，炼五金八石，以成金丹。服之可长生不老，飞升成仙。」

历史演变：

  • 先秦：方士炼丹，追求长生
  • 汉代：淮南王刘安招方士炼丹，著《淮南子》
  • 魏晋：葛洪著《抱朴子》，系统总结外丹术
  • 唐代：外丹术鼎盛，皇帝多服丹药
  • 宋代：外丹衰落，内丹兴起
  • 明清：外丹转入医药、冶金领域

核心典籍原文

《周易参同契》（魏伯阳）外丹章

以无制有，器用者空。故推消息，坎离没亡。

言不苟造，论不虚生。引验见效，校度神明。推类结字，原理为征。

坎戊月精，离己日光。日月为易，刚柔相当。土旺四季，罗络始终。青赤白黑，各居一方。皆禀中宫，戊己之功。

《抱朴子·金丹篇》（葛洪）原文

余考览养性之书，鸠集久视之方，曾所披涉篇卷，以千计矣。莫不皆以还丹金液为大要者焉。

夫金丹之为物，烧之愈久，变化愈妙。黄金入火，百炼不消，埋之，毕天不朽。服此二物，炼人身体，故能令人不老不死。

此盖假求于外物以自坚固，有如脂之养火而不可灭，铜青涂脚，入水不腐，此是借铜之劲以扞其肉也。金丹入身中，沾洽荣卫，非但铜青之外傅矣。

《抱朴子·仙药篇》原文

仙药之上者丹砂，次则黄金，次则白银，次则诸芝，次则五玉，次则云母，次则明珠，次则雄黄，次则太乙禹余粮，次则石中黄子，次则石桂，次则石英，次则石脑，次则石硫黄，次则石饴，次则曾青，次则松脂，次则桂，次则芝。

五、经典丹方详解

九转金丹（理论方）

传说：太上老君所炼，九转而成。

九转含义：

  • 每一转是一次完整的炼制周期
  • 每转一次，丹药纯度提高
  • 九转之后，丹药纯阳，可令人成仙

现代诠释：多次提纯，类似现代化学的多次结晶。

太清金液神丹

原料：金屑、水银、雄黄等

方法：

  1. 水银与金先炼成「金汞齐」
  2. 再加入雄黄等药物
  3. 入鼎封固，九转而成

功效：传说服之成仙

毒性：金汞齐含汞，雄黄含砷，剧毒

五灵丹

原理：以五行对应的矿物配制

五行矿物功效
金金屑或黄铁矿补肺
木灵芝或绿松石补肝
水硝石或云母补肾
火丹砂或硫黄补心
土雄黄或磁石补脾

魏伯阳「龙虎还丹」

原料：

  • 龙 = 水银（汞）
  • 虎 = 铅

原理：

  • 铅汞相合，阴阳交媾
  • 铅为太阴之精，汞为太阳之精
  • 二者相合，化为纯阳之丹

反应：

铅 + 汞 → 铅汞齐（合金）
铅汞齐 + 硫 → 硫化铅 + 硫化汞（黑色）
硫化铅 + 硫化汞 + 氧 → 氧化铅 + 氧化汞（红色/黄色）

现代化学：这就是古代的「铅丹」（四氧化三铅）和「朱砂」（硫化汞）的炼制过程。

葛洪「九光丹」

原料：丹砂、雄黄、雌黄、曾青、矾石、磁石、云母、石英、石膏

九光：丹成之后，发出九种颜色的光芒

现代诠释：不同矿物在高温下产生不同颜色的焰色反应或化合物。

六、炼丹流程

完整炼丹流程

1. 准备阶段（7日）

步骤内容目的
斋戒沐浴更衣，素食禁欲净化身心
选料精选矿物，去除杂质保证纯度
研磨将矿物研磨成细粉增加反应面积
配比按丹方比例混合保证配比准确

2. 炼丹阶段（49日-81日）

步骤火候时间目的
升火文火3日去除水分
转火武火7日分解矿物
养火文火21日稳定反应
结丹文火18日丹药凝结
封炉止火7日自然冷却

3. 取丹阶段

步骤内容注意
开炉待炉完全冷却后开炉防止氧化
取丹用玉勺或金勺取丹避免污染
验丹观察丹药颜色、光泽、气味判断成败
存丹用玉瓶或金瓶装丹防潮防氧化

验丹方法

方法好丹坏丹
观色色泽光亮，如珠如玉色泽暗淡，发黑发灰
闻气气味清香气味刺鼻
试火入火不化，越烧越坚入火即化，或爆裂
试水入水不溶入水即溶
试金点金成丹（传说）不能点化
试服服后身轻体健（传说）服后中毒身亡

内丹的兴起

外丹的惨痛失败促使道家转向人体内部修炼：

人物贡献
钟离权唐代，力倡内丹，著《破迷正道歌》

  • 从「服食外丹」到「修炼内丹」
  • 从「五金八石」到「精气神」
  • 从「丹炉鼎器」到「人身鼎炉」
  • 从「火候外控」到「火候内调」

具体化学成就

火药的发明

「丹房炼丹，以硝石、硫黄、木炭合炼，偶有爆炸，遂悟火药之法。」

配方：硝石（KNO₃）+ 硫黄（S）+ 木炭（C）

反应：

2KNO₃ + S + 3C → K₂S + N₂ + 3CO₂

豆腐的发明

传说淮南王刘安炼丹时，以石膏（CaSO₄）点豆浆，偶得豆腐。

合金成分炼丹用途

药金铜+锌（黄铜）仿金

矿物反应

反应现象古代描述
