大六壬课（人事） — 日用占卜的精算之法

「六壬者，水神也。壬水为阳水，寄生于申，申为坤宫，坤为地，地载万物，故六壬能知万事。」 —— 《六壬大全·序》

一、源流与典籍原文

六壬源流

传说起源：

「六壬之术，传自轩辕黄帝。黄帝战蚩尤，命风后作六壬，以占军情。后太公、张良、诸葛孔明，皆精此术。」

历史演变：

  • 黄帝时期：传说风后创六壬
  • 汉代：张良、东方朔精六壬
  • 唐代：李淳风著《六壬课》
  • 宋代：邵彦和著《六壬断案》
  • 明代：陈公献著《六壬指南》
  • 清代：张官德著《六壬辨疑》、刘赤江著《六壬粹言》

核心典籍原文

《六壬大全·序》原文

六壬之学，其来尚矣。昔者黄帝命风后作太乙，以占兵机；又命容成作六壬，以测人事。盖太乙主天，六壬主人，奇门主地，三式并兴，而六壬尤切于日用。

夫壬之为言，任也，阳也。阳生于子，子为一阳；终于亥，亥为六阳。壬寄于亥，亥为天门，故六壬能通天地人三才之道。

六壬之法，以四课三传为体，以十二月将为用，以日干为身，以日支为家，以三传为事之始终，以天将为事之吉凶。其法精密，其应如响，故古人有「占卜之王」之誉。

《六壬断案》（邵彦和）原文摘录

占者当静心诚意，焚香致敬，然后书时，起课。课成，先视日辰，次观四课，再审三传，终察将神。四课主事之现况，三传主事之终始，将神主事之吉凶。

《六壬指南》（陈公献）原文摘录

六壬之学，以断人事为最。婚姻、求财、功名、疾病、出行、失物、官司、田宅，无所不包。其法以日干为身，日支为宅，上神为外，下神为内。干上所得，谓之干上神；支上所得，谓之支上神。干上神、支上神，合曰四课。

四、起课方法详解

第一步：确定占时

记录占课的年、月、日、时（农历或干支历）。

例：2026年5月18日巳时

  • 年：丙午年
  • 月：辛巳月
  • 日：戊寅日
  • 时：丁巳时

第二步：确定月将

根据节气确定当前月将。

例：5月18日，小满后（5月21日小满）→ 四月将 申（传送）

第三步：月将加时（排天盘）

将月将加在占时的地支上，顺排十二将。

口诀：月将加时方，顺排十二将。

例：月将为申，占时为巳时

  • 申加巳宫
  • 酉加午宫
  • 戌加未宫
  • 亥加申宫
  • 子加酉宫
  • 丑加戌宫
  • 寅加亥宫
  • 卯加子宫
  • 辰加丑宫
  • 巳加寅宫
  • 午加卯宫
  • 未加辰宫

天盘排好：

    酉(午)  戌(未)  亥(申)
    申(巳)          子(酉)
    未(辰)          丑(戌)
    午(卯)  巳(寅)  辰(丑)

第四步：排四课

四课由日干和日支的上神（天盘神）组成。

第一课（干上神）：日干所在地盘宫的天盘神 第二课（干之阴神）：第一课地盘宫的天盘神 第三课（支上神）：日支所在地盘宫的天盘神 第四课（支之阴神）：第三课地盘宫的天盘神

例：戊寅日

  • 戊（日干）在地盘巳宫 → 第一课：巳（天盘神为寅）
  • 寅（第一课地盘神寅）在地盘寅宫 → 第二课：寅（天盘神为亥）
  • 寅（日支）在地盘寅宫 → 第三课：寅（天盘神为亥）
  • 亥（第三课地盘神亥）在地盘亥宫 → 第四课：亥（天盘神为申）

四课：

  • 第一课：戊上寅
  • 第二课：寅上亥
  • 第三课：寅上亥
  • 第四课：亥上申

第五步：定三传

三传由初传（发用）、中传、末传组成。

克贼法（主要取发用方法）

贼克：上克下或下克上 比用：同日干阴阳者 涉害：涉害深者为用 遥克：远相克 昴星：无克时取酉宫 别责：无克时特殊取法 八专：八专日特殊取法

克贼优先级：

  1. 上克下（克）：上神克下神
  2. 下贼上（贼）：下神克上神
  3. 比用：与日干阴阳相同者
  4. 涉害：涉害深者（克多者）

例：戊寅日四课

  • 第一课：寅上戊（寅克戊？寅木克戊土，是！）
  • 第二课：亥上寅（水生木，不克）
  • 第三课：亥上寅（同上）
  • 第四课：申上亥（金生水，不克）

第一课寅木克戊土（上克下），发用为寅。

中传：发用寅的地盘宫（寅宫）的天盘神 = 亥 末传：中传亥的地盘宫（亥宫）的天盘神 = 申

三传：寅 → 亥 → 申

第六步：排十二天将

天将排列：根据日干和占时阴阳定贵人位置，然后顺排或逆排。

贵人起法：

  • 甲戊庚牛羊（昼丑夜未）
  • 乙己鼠猴乡（昼子夜申）
  • 丙丁猪鸡位（昼亥夜酉）
  • 壬癸蛇兔藏（昼巳夜卯）
  • 六辛逢马虎（昼午夜寅）

顺逆：占时在地盘亥子丑寅卯辰（前六宫）顺排，在地盘巳午未申酉戌（后六宫）逆排。

例：戊寅日丁巳时

  • 日干戊 → 贵人：昼丑、夜未（丁巳时为昼，贵人起丑）
  • 占时巳 → 在地盘后六宫（巳午未申酉戌）→ 逆排

七、分类占断详解

求财占

用神：妻财、子孙、兄弟

判断因素吉凶
妻财旺相财可得财难得
子孙旺相财源广财源断
兄弟旺相劫财竞争大
官鬼旺相官方得财病耗财
三传妻财过程得财过程破财
贵人乘财贵人带财—
青龙乘财正财—
玄武乘财暗财暗失

断语：

  • 妻财旺相，子孙生妻财 → 求财大利
  • 兄弟旺相克妻财 → 求财有阻，或被劫夺
  • 官鬼旺相克兄弟 → 官方保护，求财可成
  • 三传见财，末传吉 → 财可到手

工作事业占

用神：官鬼、贵人、父母

判断因素吉凶
官鬼旺相事业有成事业受阻
贵人临身有贵人提拔无贵人
父母旺相文书有利文书不利
青龙临官事业兴旺—
朱雀临官口舌是非—
三传官鬼过程有职过程有灾

断语：

  • 官鬼旺相，贵人临身 → 升职有望
  • 官鬼被子孙克 → 辞职或降职
  • 官鬼被兄弟克 → 同事竞争
  • 青龙临官禄 → 事业大吉

婚姻占

男命：

  • 妻财旺相 → 妻贤
  • 六合旺相 → 婚姻可成

女命：

  • 贵人临身 → 有贵人媒

八、六壬课例

课例一：求财

时间：假设某年某月某日午时 占问：投资股票能否获利？

起课：

  • 日干：甲
  • 日支：辰
  • 月将：某将
  • 占时：午

排盘：

  • 四课：干上某神，支上某神
  • 三传：初传某，中传某，末传某
  • 天将：贵人某处，青龙某处

分析：

  • 妻财爻旺相 → 财可得
  • 子孙爻生财 → 财源有
  • 兄弟爻不旺 → 无劫财
  • 三传财爻 → 过程得财

结论：可投资，有获利。
