太乙神教（国事） — 国运预测的帝王秘术

「太乙者，北极之神也。以太乙之数，推国运之兴衰，此帝王南面之术，非庶人所得而闻也。」 —— 《太乙金镜式经》

「三式之中，太乙推天运，奇门择兵机，六壬决人事。太乙居首，以其推天运、占国祚，最为宏大。」 —— 三式总论

一、源流与典籍原文

太乙神数源流

传说起源：

「太乙神数，传自黄帝。黄帝命风后作太乙，以占兵机、推国运、测天灾。后历代帝王，皆秘藏于钦天监，不许民间私习。」

历史演变：

  • 上古传说：黄帝战蚩尤，命风后创太乙九宫之法，以定八方军阵
  • 周代：用于国家祭祀、战争决策，太公望（姜子牙）精于此术
  • 春秋战国：诸子百家争呜，太乙术散入方士之手
  • 汉代：司马迁《史记·天官书》记载太乙占法，太史令掌天文历法兼及太乙
  • 魏晋：管辂、郭璞等以易数通太乙，渐与奇门、六壬分流
  • 唐代：王希明著《太乙金镜式经》，系统总结太乙术数，为现存最早太乙专著
  • 宋代：太乙与奇门、六壬并称「三式」，为皇家秘术。沈括《梦溪笔谈》载太乙占验
  • 明清：钦天监专掌太乙，用于预测国运、天灾、皇帝本命流年。民间偶有抄本流传

典籍目录：

典籍作者/年代特点
《太乙金镜式经》唐·王希明现存最早系统太乙专著
《太乙统宗》明·佚名集大成之作，最为完备
《太乙局》明排局方法
《太乙秘书》清民间抄本
《太乙数统宗大全》清汇集各家

核心典籍原文

《太乙金镜式经》（唐·王希明）原序

太乙者，天帝之神也。居紫微垣，统御万方。其数以九宫为体，以三基为纲，以四郭为目，以八门为用。推之则国运可知，占之则天灾可测。

夫太乙之数，上推三皇，下及万世。以积年之术，算太乙所在之宫；以三基之法，判君臣民之吉凶；以四郭之门，定开闭之期；以八神之位，审祸福之源。

太乙所在，若居九宫，则君位端正，国泰民安；若居一宫，则暗昧不明，内有阴谋；若居七宫，则刑罚太重，天灾流行。此太乙之大略也。

三基者，君基、臣基、民基也。君基旺则国运昌，臣基旺则政治清，民基旺则社会安。三基俱旺，天下大治；三基俱衰，天下大乱。

然太乙之术，非大智慧者不能学，非大德者不能用。用之正则正，用之邪则邪。故古人秘之，不轻示人。

《太乙金镜式经》正文摘录

太乙九宫：一宫名太阴，二宫名摄提，三宫名轩辕，四宫名招摇，五宫名天符，六宫名青龙，七宫名咸池，八宫名太阴，九宫名天乙。

太乙起宫法：上元甲子算起，积年至所求之年，除周天三百六十，余为太乙之积。以积入宫，一宫三年，八宫三年，三宫三年，四宫三年，九宫四年，二宫二年，六宫二年，七宫二年，五宫不入。

三基求法：君基起一宫，臣基起二宫，民基起三宫。各以积年入宫，与太乙同法，但所用之年数有异。

主客之分：太乙为主，天目为客。主客相生则和，相克则战。主胜客则内政修明，客胜主则外患频仍。

《太乙统宗》原文摘录

太乙积年，以上元甲子为始。积年之数，除周天之数，余为太乙所在之宫。太乙每宫停留，或三年，或二年，或四年，各有定数。

太乙行宫次第：一宫三年，八宫三年，三宫三年，四宫三年，九宫四年，二宫二年，六宫二年，七宫二年，五宫不入。

太乙所在之宫，配以三基、四郭、八门、八神，则吉凶可判，国运可知。

天目者，监察之神也。天目与太乙同宫，则臣下不忠；天目冲太乙，则朝野震动。

始击者，兵戈之神也。始击动则兵革起，始击静则天下安。

文昌者，文运之神也。文昌旺则文化昌明，文昌衰则学术凋零。

二、太乙式盘结构详解

1. 太乙九宫

太乙式盘以洛书九宫为空间框架，但九宫的名称、意义与奇门遁甲不同：

宫位名称方位五行主事停留年数吉凶
一宫太阴北水暗中谋划、阴谋、暗藏3年暗昧不明
二宫摄提西南土辅助、提携、后援2年辅助之力
三宫轩辕东木生发、开创、出征3年开国大吉
四宫招摇东南木动荡、变动、迁移3年多事之秋
五宫天符/中宫中土中央枢纽、皇帝、权力核心不入至尊之位
六宫青龙西北金权威、军队、法律2年武力征伐
七宫咸池西金灾变、刑罚、瘟疫、战乱2年天灾人祸
八宫太阴东北土收藏、归藏、终结、休养3年休养生息
九宫天乙/太乙南火君位、帝王、光明、昌盛4年国泰民安

九宫歌诀：

一宫太阴暗中藏，二宫摄提辅君王。 三宫轩辕开新宇，四宫招摇动四方。 五宫天符居帝座，不入轮回守中央。 六宫青龙扬威武，七宫咸池灾祸降。 八宫太阴归藏地，九宫天乙照万方。

2. 三基（君基、臣基、民基）

三基是太乙神数中判断国家三层结构吉凶的核心指标：

基代表起宫主事旺象衰象
君基君主、中央、最高权力一宫（太阴）国运、皇权、决策君明臣贤，政通人和君弱臣强，权臣当道
臣基大臣、政府、官僚体系二宫（摄提）政治清明、行政效率忠臣当道，政治清明奸臣当道，政治腐败
民基百姓、民生、社会经济三宫（轩辕）社会安定、民生富足百姓安居乐业民不聊生，动荡不安

三基与太乙的关系：

  • 三基与太乙同宫或相生：该层大吉
  • 三基与太乙相冲或相克：该层有灾
  • 君基克太乙：权臣犯上
  • 太乙克君基：君主专制
  • 三基俱旺：天下大治（如贞观之治）
  • 三基俱衰：天下大乱（如末年乱世）

3. 四郭（四门/四正门）

四郭是太乙式盘中的时间-空间门户，决定吉凶的”出入口”：

门方位五行吉凶含义国运对应
开门乾（西北）金大吉开国、开创、开端、开张新朝建立、新政策出台
休门坎（北）水吉休息、和平、休养、和解和平年代、休养生息
生门艮（东北）土吉生发、生长、生育、生财经济繁荣、人口增长
杜门巽（东南）木凶闭塞、不通、受阻、终结闭关锁国、政策僵化

四郭用法：

  • 太乙临开门 → 宜开国、改革、出征
  • 太乙临休门 → 宜和谈、休养、停战
  • 太乙临生门 → 宜发展经济、鼓励生育
  • 太乙临杜门 → 不宜大事，宜守成

4. 八神（太乙八将）

八神是太乙式盘中最重要的神煞系统：

三、太乙推算方法详解

1. 求太乙积年

上元甲子

太乙以上元甲子为起点，历代有不同的上元设定：

流派上元甲子说明
黄帝上元公元前2697年传说黄帝即位之年
太古上元公元前9567年更古老的设定
近世上元公元前年数不定各流派自定

现代常用：以公元前2697年为黄帝元年，作为太乙积年的起点。

积年计算公式

积年数 = 所求年 - 上元年

例如：求2025年的太乙宫位
积年数 = 2025 - (-2697) = 2025 + 2697 = 4722年

太乙入宫

太乙积 = 积年数 mod 360
（若结果为0，则取360）

360为一「大周」，代表天地一周的气数循环。

太乙行宫分配

太乙积确定后，按以下次序分配入宫：

顺序宫位停留年数累计年数
1一宫（太阴）3年1-3
2八宫（太阴）3年4-6
3三宫（轩辕）3年7-9
4四宫（招摇）3年10-12
5九宫（天乙）4年13-16
6二宫（摄提）2年17-18
7六宫（青龙）2年19-20
8七宫（咸池）2年21-22
9五宫不入——

一个完整周期：3+3+3+3+4+2+2+2 = 22年

计算方法：

周期数 = 太乙积 ÷ 22 = 商（大周期数）+ 余数（入宫基数）

余数对应宫位：
余1-3 → 一宫
余4-6 → 八宫
余7-9 → 三宫
余10-12 → 四宫
余13-16 → 九宫
余17-18 → 二宫
余19-20 → 六宫
余21-22（或0）→ 七宫

2. 三基求法

三基的起宫与太乙不同，入宫方法也不同：

基起宫入宫方法
君基一宫（太阴）君基积 = 积年数 mod 180，按君基周期分配
臣基二宫（摄提）臣基积 = 积年数 mod 90，按臣基周期分配
民基三宫（轩辕）民基积 = 积年数 mod 60，按民基周期分配

三基周期：

  • 君基周期：180年（一个大运）
  • 臣基周期：90年（一个中运）
  • 民基周期：60年（一个甲子周期）

3. 主客算

主客算是太乙术中判断内外形势的核心：

算起法主事
主算太乙本宫数 + 宫位数内政、君主、我方
客算天目所在宫数 + 宫位数外交、大臣、敌方
和算主算 + 客算总和，判断大势

判断：

  • 主算 > 客算：内政强于外交，我方占优
  • 客算 > 主算：外患大于内忧，敌方强势
  • 主算 = 客算：势均力敌，需看其他因素
  • 主算或客算为单数（阳）：主动、进攻
  • 主算或客算为双数（阴）：被动、防守

4. 四郭（门）的求法

四郭根据太乙入宫的年份确定：

太乙入宫年数开门休门生门杜门
第1年乾（西北）坎（北）艮（东北）巽（东南）
第2年顺时针转一宫同上同上同上
第3年再转一宫同上同上同上

即：四郭每年顺时针移动一位，循环往复。

5. 八神排法

八神的位置根据太乙宫位和当年干支确定：

神定位方法
太乙太乙本宫
天目太乙对冲宫（对宫）
文昌太乙前一位宫
始击太乙后一位宫
主客主算所在宫/客算所在宫
四神太岁所在宫
计神文昌对冲宫
太岁当年地支对应的宫位

五、太乙实例推算

实例一：2025年（乙巳年）太乙占

步骤：

  1. 求积年：2025 - (-2697) = 4722年
  2. 求太乙积：4722 mod 360
    • 4722 ÷ 360 = 13余42
    • 太乙积 = 42
  3. 求宫位：42 ÷ 22 = 1余20
    • 余20 → 对应七宫（咸池）

判断：

  • 2025年太乙居七宫咸池
  • 咸池主灾变、刑罚、瘟疫
  • 三基：需进一步计算君基、臣基、民基
  • 国运判断：该年需注意天灾人祸、刑罚冤案、瘟疫流行
  • 对策：宜减刑、安抚、防灾、加强医疗卫生

实例二：唐太宗贞观年间（627-649）

简化推算：

  • 太乙积年 ≈ 627 + 2697 = 3324
  • 3324 mod 360 = 3324 - 360×9 = 3324 - 3240 = 84
  • 84 ÷ 22 = 3余18
  • 余18 → 对应**九宫（天乙）**→ 余数落在九宫范围内（13-16），但18超过16，需要重新检查

实际上更精确的计算需要完整的太乙盘，这里只是示意。

历史验证：

  • 贞观年间确为唐朝盛世
  • 太乙居九宫天乙 → 君位端正，国泰民安 → 与史实吻合

实例三：安史之乱（755-763）

简化推算：

  • 755年为唐玄宗天宝十四载
  • 太乙积年 ≈ 755 + 2697 = 3452
  • 3452 mod 360 = 3452 - 360×9 = 3452 - 3240 = 212
  • 212 ÷ 22 = 9余14
  • 余14 → 对应九宫（天乙），但安史之乱时天乙应为凶象

说明：

  • 太乙术需要完整的盘局（含三基、四郭、八神）才能准确判断
  • 单看太乙宫位不足以断吉凶
  • 755年安史之乱时，需看始击是否发动、主客算是否失衡等

太乙与改元

古代帝王常在太乙不利时改元（更换年号）：

帝王改元次数与太乙关系
汉武帝11次多次改元与太乙入凶宫有关

改元的意义：

  • 更换年号 = 更换”国运”的起点
  • 希望通过改元改变太乙积年的计算
  • 心理安慰 + 政治宣示

十二、太乙术的数学原理

模运算与周期论

太乙术的核心数学原理是模运算（Modular Arithmetic）：

运算公式现代数学
积年 mod 360余数为太乙大周期位置模360运算
余数 mod 22余数为宫位模22运算
三基 mod 180/90/60君/臣/民基的周期模运算
四郭旋转每年+1 mod 8模8运算

周期叠加：

  • 太乙大周期：360年
  • 太乙行宫周期：22年
  • 三基周期：60-180年
  • 四郭周期：8年
  • 太岁周期：60年

多个周期的叠加产生了复杂的拍频效应。

周期与天象

太乙周期可能的天文对应说明
22年2×11年（太阳黑子周期）可能古人观察到某些22年周期
60年五星小周期（会合周期）五星约60年回到近似位置
360年中国古代历法周期一年360日（古代近似）

概率论视角

从概率论看太乙术：

要素随机性分析
九宫吉凶太乙入九宫，某些宫定义为大吉/大凶
三基旺衰三基与太乙的关系有生克
主客算主客大小关系有胜负
历史验证选择性记忆：只记得中的，忘记不中的

巴纳姆效应：太乙断语多为模糊的吉凶描述，后人根据历史事件反向附会。

十四、太乙术与《易经》

太乙与易理

太乙易经对应

积年周期元会运世时间周期
太乙入九宫乾卦「飞龙在天」君位大吉

太乙与邵雍《皇极经世》

体系时间单位周期

皇极经世元、会、运、世129600年一元

两者都试图以数学周期来推演历史大势，体现了中国古代历史周期论的思想。
