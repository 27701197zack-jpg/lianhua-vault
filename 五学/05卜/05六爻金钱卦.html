六爻金钱卦 — 随手可占的简易法门

「三人同心，其利断金。钱挂虽小，能通神明。」 003e —— 六爻入门

一、源流与典籍原文

六爻源流

传说起源： 003e 「六爻之法，源自伏羲画卦，文王演易，周公作爻辞，孔子作十翼。至汉京房，创纳甲法，以干支纳入卦中，六爻之术始成。」

历史演变：

  • 上古：伏羲画卦，以蓍草占卜
  • 周代：《周易》大衍筮法
  • 汉代：京房创纳甲法、飞伏法、世应法
  • 魏晋：管辂以象为主
  • 唐代：火珠林以金钱代蓍
  • 宋代：麻衣道者著《火珠林》
  • 明代：《卜筮全书》《断易天机》
  • 清代：王洪绪著《卜筮正宗》，集六爻之大成

核心典籍原文

《卜筮正宗》（王洪绪）原序

003e 卜筮之道，通于神明。上以考天意，下以察民心。其法以六爻为体，以五行为用，以世应为纲，以六亲为目，以六神为佐，以动静为变，以旺衰为断。 003e 003e 夫六爻者，初二三四五上也。初为始，上为终，二为内，五为尊，三为人，四为时，六爻周流，变化无穷。其静者，体也；其动者，用也。体用相生，则吉；体用相克，则凶。 003e 003e 世者，身也，我之象也；应者，对也，彼之象也。世应相生相合，则事易成；世应相克相冲，则事难就。世旺应衰，我强彼弱；世衰应旺，我弱彼强。 003e 003e 六亲者，父母、兄弟、子孙、妻财、官鬼也。父母主文书、长辈、房屋；兄弟主朋友、同事、竞争；子孙主晚辈、财源、解忧；妻财主妻子、财产、资源；官鬼主官职、工作、疾病、小人。各以其类，而占各以其事。 003e 003e 六神者，青龙、朱雀、勾陈、螣蛇、白虎、玄武也。青龙主喜庆、财喜；朱雀主口舌、文书；勾陈主迟滞、田土；螣蛇主虚惊、怪异；白虎主刑伤、疾病；玄武主盗贼、阴私。六神临六亲，则吉凶可判。 003e 003e 旺衰者，四时之气候也。春木旺、火相、土死、金囚、水休；夏火旺、土相、金死、水囚、木休。各以其时而论其气，气旺则吉，气衰则凶。 003e 003e 动静者，变化之机也。静爻为体，动爻为用。动则变，变则通。动爻生世，则有人来助；动爻克世，则有人来害。动爻化吉，则事终有成；动爻化凶，则事终有败。 003e 003e 学者熟记卦象，明辨五行，详察世应，细推六亲，则吉凶可判，休咎可知。然卜筮虽能知来，终不如修德。积善之家，必有余庆；积不善之家，必有余殃。故卜筮之余，尤当修德。

《黄金策》（刘伯温）原文摘录

003e 总论： 003e 动静阴阳，反复迁变。虽万象之纷纭，须一理而融贯。夫人有贤不肖之殊，卦有过不及之异。太过者，损之斯成；不及者，益之则利。 003e 003e 身命： 003e 世为身，应为人，大宜契合；财为福，鬼为祸，最忌交重。世旺身强，必主安康无疾；财生鬼合，定然灾患萦缠。 003e 003e 求财： 003e 财旺福兴，公私称意；财空福绝，上下违心。财生官鬼，利求官而亦求财；鬼克弟兄，为损财而因致讼。 003e 003e 婚姻： 003e 阴阳得位，贤夫淑女；世应相生，白头相守。财鬼相合，必谐秦晋之姻；世应相冲，难定丝罗之好。 003e 003e 疾病： 003e 鬼旺克身，病必沉重；子兴福至，药乃通灵。用值鬼爻，近病遄瘳而远病反覆；身临福德，内病难疗而外病无妨。 003e 003e 官讼： 003e 世官相合，必主和解；鬼克身爻，定然败诉。父化官鬼，文书终有变；财化兄弟，钱财定有伤。 003e 003e 出行： 003e 子旺财明，行人立至；世空应绝，远客难来。用兴福合，路逢故友；鬼发兄摇，途遇小人。 003e 003e 失物： 003e 财在内爻，物未散失；财在外卦，物已移远。鬼化文书，贼人已获；子化妻财，失物可寻。

二、起卦方法详解

准备铜钱

传统用乾隆通宝三枚：

  • 正面（有字/满文）= 阴（字）
  • 反面（无字/光背）= 阳（背）

现代可用硬币代替，但需统一规则。

摇卦步骤

步骤：

  1. 静心：双手捧铜钱，默想所占之事
  2. 摇卦：双手合扣铜钱，摇动数次
  3. 投掷：将铜钱轻轻撒在桌面
  4. 记录：观察三枚铜钱的正反面
  5. 重复：重复6次，从初爻到上爻

记录方法

铜钱结果总和爻象阴阳变否记号
三反面（背背背）3×2=6老阴阴变爻×
两反一正（背背字）2+2+3=7少阳阳不变—
两正一反（字字背）3+3+2=8少阴阴不变- -
三正面（字字字）3×3=9老阳阳变爻○

记忆口诀：

  • 「三背为老阳（变阴）」→ 9，阳爻变阴爻
  • 「三字为老阴（变阳）」→ 6，阴爻变阳爻
  • 「两背一字为少阳」→ 7，阳爻不变
  • 「两字一背为少阴」→ 8，阴爻不变

用神取用原则

用神多现

当卦中出现多个用神时：

  1. 取旺相者为用神
  2. 取持世者为用神
  3. 取动爻者为用神
  4. 取不破空者为用神

用神不现

当卦中不出现用神时：

  1. 查伏神（用神伏于某爻之下）
  2. 以飞神生伏神者可出
  3. 以日辰冲飞神者可出

七、分类占断详解

求财占

用神：妻财爻

判断因素吉凶
妻财旺相财运好财运差
妻财持世财可得财难得
妻财动而生世主动来财—
妻财空破—财落空
兄弟旺动—劫财
子孙旺动财源广—
官鬼旺动—官非破财

断语：

  • 财旺生世，求之必得
  • 财空破绝，求之难得
  • 兄动劫财，投资失利
  • 子动生财，财源广进

求官占

用神：官鬼爻

判断因素吉凶
官鬼旺相官运好官运差
官鬼持世官可得—
官鬼动而生世提拔有望—
官鬼空破—官落空
子孙旺动—克官
父母旺动文书有利—
财动生官财官相生—

断语：

  • 官旺生世，升职有望
  • 官空破绝，难升职
  • 子动克官，降职或免职
  • 财动生官，财官双美

考试占

用神：父母爻

判断因素吉凶
父母旺相成绩好成绩差
父母持世可考中—
父母动而生世考试顺利—
父母空破—考不中
财动克父—不利
官动生父官印相生—
子动克官—不利

断语：

  • 父旺生世，必考中
  • 父空破绝，考不中
  • 财动克父，分心失利
  • 官动生父，金榜题名

婚姻占

男命：

  • 用神：妻财爻
  • 财旺相持世 → 妻贤
  • 财空破 → 婚姻难成
  • 财动化凶 → 妻有灾

女命：

  • 用神：官鬼爻
  • 官旺相持世 → 夫贤
  • 官空破 → 婚姻难成
  • 官动化凶 → 夫有灾

断语：

  • 财官旺相，婚姻可成
  • 财官空破，难成
  • 世应相生相合，婚姻美满
  • 世应相冲相克，婚姻不和

疾病占

用神：官鬼爻（病），子孙爻（医药），父母爻（处方）

判断因素吉凶
官鬼旺相病重—
官鬼休囚病轻—
子孙旺相医药有效—
子孙克官鬼病可愈—
官鬼动化凶病情恶化—
官鬼动化吉病情好转—
用神入墓病重—
用神空绝危—

断语：

  • 子旺克鬼，病可愈
  • 鬼旺无制，病重
  • 鬼动化子，病渐愈
  • 鬼动化鬼，病转重
  • 用神入墓，病难愈
  • 用神空绝，病危

出行占

用神：世爻（行人），应爻（目的地）

判断因素吉凶
世爻旺相出行顺利—
世爻空破—不宜出行
应爻旺相目的地吉—
世应相生出行有利—
世应相冲—出行不利
官鬼旺动—有灾
子孙旺动平安—

断语：

  • 世旺应吉，出行顺利
  • 世空破绝，不宜出行
  • 鬼动克世，出行有灾
  • 子动护身，平安无事

失物占

用神：妻财爻（失物）

判断因素吉凶
财爻旺相物未损—
财爻空破—已失
财爻入墓物在某处—
财爻伏藏物在暗处—
子孙克官鬼可找回—
官鬼旺动—被盗
玄武临财—被盗

断语：

  • 财旺子兴，可找回
  • 财空鬼旺，已不可找回
  • 财入墓，在某处藏
  • 财伏藏，在暗处
  • 玄武临财，被盗
